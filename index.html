桌面宠物·法理 隐私政策

温馨提示

欢迎使用「桌面宠物·法理」。本产品由夏奶奶的神秘工坊开发和维护，是一款 Windows 桌面宠物，提供翻阅法典、打字陪伴、桌面战斗、薅毛互动、提醒和本地设置功能。

当前 Windows 版本无需注册登录，可离线使用。程序不会把按键事件、输入文字或本地存档自动上传给开发者。打字陪伴会在本机接收键盘事件以判断书写与回车动作；键控和拖动会在本机处理按键、鼠标位置等信息。您的台词、提醒和游戏进度保存在本机文件中。请阅读下文了解具体处理方式。

我们重视您的个人信息和隐私。本政策适用于「桌面宠物·法理」当前 Windows 桌面版，以及您通过本政策所列联系方式主动向我们反馈问题的情形。下载平台、邮件服务和本页面托管服务由相应第三方独立提供，其自身的信息处理适用各自的隐私规则。

本政策沿用平台隐私政策模板的内容结构，并根据本产品实际功能说明适用情况。当前版本没有独立的用户账号、真实货币充值或在线生成式 AI 对话服务。请在使用前阅读本政策；不希望程序继续接收本地键鼠事件时，可通过右键菜单退出桌宠。

一、我们如何收集和使用您的个人信息

（一）功能所需的本地处理

本产品不要求提供姓名、手机号码、身份证号、银行卡号或账号密码来运行。程序为实现您选择的功能，会在您的设备上处理以下信息：

功能与目的处理的信息保存与传输方式
打字陪伴：让法理书写并在回车后投羽键盘事件中的按键代码、按下或松开状态，以及 Ctrl、Alt 等修饰键状态，用于判断是否存在书写活动或回车操作。通过 Windows 键盘事件接口在本机即时判断。不读取输入框正文，不重建您输入的文章、聊天内容或密码，不保存按键序列或输入文本，不上传键盘事件。
战斗键控、自定义按键和鼠标互动当前按键状态、自定义快捷键、鼠标位置、拖动方向和移动速度等。键鼠状态在本机用于移动、攻击、拖动和甩羽毛。自定义按键绑定会写入本地存档；连续操作轨迹不作为记录保存或上传。
保持人物与界面的位置和显示效果屏幕边界、显示缩放、人物坐标、窗口状态、语言和字号等设置。运行时在本机使用；必要的位置和偏好设置保存在本地存档。不采集设备唯一标识符用于识别用户。
保存游戏进度与互动状态金币、经验、可薅次数、战绩、自定义属性、零食效果和进食进度等。仅写入程序目录中的本地存档及备份，没有云存档或自动同步功能。游戏内金币不是现实货币。
自定义台词、闹钟和倒计时您主动填写的台词、提醒事项、日期和时间、计时设置，以及本机系统时间。内容写入本地存档，用于显示台词和提醒；不自动发送给开发者。您主动填写的内容可能包含个人信息，请自行决定填写范围。
运行故障排查异常类型、异常信息、调用栈等；错误信息可能包含本机文件路径。发生异常时可能在程序目录生成「运行错误.txt」，不自动上传。只有您主动发送给我们时，我们才会收到该文件。
回复您主动提交的问题您发送邮件时使用的邮箱、邮件正文，以及自愿提供的截图、日志或附件。用于回复、排查您报告的问题及处理隐私请求。发送前可遮挡截图中的私人内容，并删除无关附件。

（二）键盘事件与功能开关

程序运行时会安装本地 Windows 键盘事件监听，用于识别活动和功能按键。选择「打字陪伴」后，书写活动才会驱动对应动画；通常的翻阅法典模式不触发打字投羽。战斗键控启用后，可通过按键控制人物；按 Esc 可暂停并释放战斗键控。切回通常模式并不等同于卸载键盘监听；完全停止本程序的键盘事件监听，请右键选择「退出桌宠」。监听在退出时解除。

这些 Windows 桌面接口不同于手机上的相机、麦克风等授权弹窗，程序不会为每次按键弹出系统权限请求。当前版本不调用相机、麦克风、通讯录或定位权限，不截取您的桌面内容用于上传，也不读取剪贴板内容。

（三）模板中不适用的服务

当前版本不提供账号注册、登录、实名认证、真实货币充值、在线支付、广告投放或面向玩家的 AI 内容生成服务；不为这些目的收集手机号码、身份证件、支付信息、广告标识符或网络访问记录。零食和薅毛消耗的是游戏内金币，不发生现实货币支付。

（四）用途限制

我们只按本政策说明的目的使用收到的信息。若未来版本新增网络服务、云同步、SDK 或其他信息处理用途，我们会先更新说明，并依法履行必要的告知和授权程序，不以本政策概括授权尚未提供的功能。

二、我们如何保存您的个人信息

游戏进度和设置保存在程序所在文件夹的 法理存档.xml 及 法理存档.xml.bak 中。保存过程中可能短暂生成 法理存档.xml.new。错误记录如有生成，也保存在程序目录。存档是本地 XML 文件，当前没有加密功能。能够访问该文件夹的其他程序或人员，可能读取其中的自定义台词、提醒等内容。

程序本身不把这些本地数据存入开发者服务器，也不自动上传或跨境传输。若您把程序放入第三方云盘同步文件夹，或者主动复制、备份和分享存档，相应传输由您的操作和第三方服务决定。

本地存档会保留到您主动删除；仅退出桌宠不会清除进度。您主动发送给我们的反馈材料，仅在解决问题、响应请求和履行适用义务所需的期限内保留，目的完成后予以删除或进行必要处理。您可以通过联系邮箱提出查询或删除请求。

三、我们如何使用 Cookies 和同类技术

本桌面程序不使用 Cookies、广告追踪标识或浏览器追踪技术。本政策网页不包含广告、第三方分析脚本或用于识别访客的自行设置 Cookies。提供网页托管、下载或邮件服务的第三方，可能按其服务规则处理连接和运行所需的信息；该行为不代表桌宠向其上传了本地存档或按键事件。

四、我们如何共享、转让、公开披露您的个人信息

当前版本不会把本地存档、键鼠事件或您填写的台词与提醒自动共享、转让或公开披露给第三方，也不出售这些信息。

对于您主动反馈后由我们收到的材料，我们不会用于无关的广告或营销。确需向第三方提供时，将依法说明接收方、用途和信息范围并取得所需授权；依法必须提供的情形按适用法律要求处理。涉及运营主体变更且实际发生个人信息转移的，我们会依法告知并要求接收方继续保护相关信息。

五、第三方产品或服务如何获得您的个人信息

当前 Windows 版本没有接入第三方广告、统计、支付、账号登录或云端 AI SDK。程序使用 Windows 和 .NET Framework 的桌面运行接口，这些接口本身不意味着我们向某个广告或分析服务发送了用户数据。

您从 TapTap 等平台下载、评价游戏，或使用邮件向我们反馈时，相应平台独立处理其服务所需的信息。此隐私政策网页使用第三方网页托管；访问网页时，托管服务可能处理 IP 地址、请求时间和浏览器信息等连接数据，具体以其隐私政策及服务说明为准。游戏程序不会把键盘事件、输入内容或本地存档发送到本网页。

六、我们如何保护您的个人信息

我们通过本地处理、减少保存范围、不自动上传、限制反馈材料用途等方式降低信息暴露风险。存档保留本地备份，用于在主存档异常时恢复；备份也可能包含旧台词和旧提醒，因此删除数据时请一并处理备份。

请妥善管理程序文件夹和设备账号，不要把包含私人信息的存档、截图或日志随意公开。当前版本不能保证本地文件免受您设备上其他软件或其他使用者访问。如发现涉及我们实际持有信息的安全事件，我们将采取补救措施，并依法履行必要的通知和报告义务。

七、您如何管理您的个人信息

  • 访问与更正：通过右键菜单的聊天设置、闹钟／倒计时、语言、字号、按键设置等入口查看和修改相关内容。您也可先退出程序，再自行备份或查看本地 XML 存档。
  • 删除自定义内容：在聊天设置中清空不需要的台词，在计时设置中取消不需要的提醒；旧内容仍可能存在于存档备份中。需要删除全部本地记录时，请先退出，再删除 法理存档.xml、法理存档.xml.bak、可能残留的 法理存档.xml.new 及需要删除的 运行错误.txt。再次启动会使用默认状态。
  • 停止相关处理：离开打字陪伴可停止对应投羽互动；按 Esc 可暂停战斗键控。完全停止本程序的键鼠监听和本地处理，请右键退出桌宠，或结束该程序进程。
  • 注销账户：本产品没有账号系统，无需办理账户注销。停止使用并按上述方式删除本地文件即可清除本机记录。
  • 反馈材料与其他请求：对于您已通过邮件提供给我们的信息，可以通过下方邮箱申请查询、更正、删除或提出投诉。请提供足以定位问题的说明，我们不会要求您提供与请求无关的敏感信息。

对于合理请求，我们原则上不收取费用。依法无法执行的请求，我们会说明原因。删除本地存档会同时删除游戏进度，请按自己的需要先备份；开发者无法从服务器为您找回已经删除的本地存档。

八、我们如何处理未成年人的个人信息

我们重视未成年人的个人信息保护。未成年人请在监护人指导下阅读本政策并使用本产品，尤其不要在公开截图、台词、提醒或反馈邮件中随意填写姓名、学校、住址、联系方式等私人信息。

当前版本不设账号和在线收集流程。对于因反馈而收到的未成年人信息，我们仅在处理问题所必要、监护人依法授权或法律允许的范围内使用。涉及不满十四周岁未成年人个人信息的处理，我们将依法取得监护人同意并采取相应保护措施。监护人如有查询或删除需求，可通过下方邮箱联系我们。

九、本隐私政策如何更新

本政策会随功能和信息处理方式的实际变化而更新，更新日期显示在页面顶部。涉及新增收集种类、使用目的、接收方或其他重大变化时，我们会通过政策页面、版本说明或发行页面作出说明，并依法履行必要的告知和授权程序。我们不会通过更新政策减损您依法享有的权利。

我们会保留相应版本记录；您需要查阅旧版本或确认某个版本的处理方式时，可以联系我们。
